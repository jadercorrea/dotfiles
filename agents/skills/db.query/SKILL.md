---
name: db.query
description: Open SQL editor (pgweb) for a target database (dev, fly, xata)
title: DB Query SQL Editor
---

This skill opens the SQL editor (pgweb) in the browser for a target database environment.
It accepts an optional database target parameter: `dev` (default, local database), `fly` (production fly.io postgres), or `xata` (production xata RAG).

Run this command in the terminal:
zapfy db query [target]
